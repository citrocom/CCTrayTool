# CCTrayTool – Руководство пользователя

[English](../README.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Español](README.es.md) · [Français](README.fr.md) · [Polski](README.pl.md) · [Magyar](README.hu.md) · **Русский**

CCTrayTool - это небольшая утилита для Windows, которая работает в виде значка в области уведомлений (внизу справа, рядом с часами). Она объединяет четыре полезные функции в одной программе:

1. **KeepAwake** – не позволяет ПК переходить в режим энергосбережения или отключать экран
2. **AlwaysOnTop** – удерживает любое окно поверх других окон с помощью сочетания клавиш
3. **Быстрый запуск инструментов** – запускает часто используемые программы прямо из меню области уведомлений
4. **CloseGuard** – блокирует кнопку закрытия (X) выбранных окон с помощью сочетания клавиш или правил

Все функции управляются через меню, открываемое щелчком правой кнопкой мыши по значку в области уведомлений. Установка не требуется, программу можно запускать напрямую.

CCTrayTool поддерживает следующие языки: английский, немецкий, итальянский, испанский, французский, польский, венгерский и русский. Язык устанавливается автоматически на основе языка системы компьютера.

Системные требования: необходима 64-разрядная версия Windows 10 или новее. Программа не работает в 32-разрядной версии Windows.

## 1. Запуск и первый значок

После запуска в области уведомлений панели задач Windows появляется значок. Цвет значка сразу показывает текущее состояние KeepAwake:

- Белый = KeepAwake отключен (обычное поведение Windows)
- Красный = KeepAwake активен для мониторов
- Синий = KeepAwake активен для системы
- Зелёный = KeepAwake активен для мониторов и системы

Щелчок правой кнопкой мыши по значку открывает меню со всеми функциями. Если значок не виден, стоит проверить область "скрытых значков" (маленькая стрелка на панели задач).

Примечание: CCTrayTool можно запустить только один раз одновременно. Повторный запуск не имеет никакого эффекта, если программа уже работает.

## 2. KeepAwake - предотвращение энергосбережения

В разделе меню "KeepAwake" можно выбрать, что ПК НЕ должен делать, пока запущен CCTrayTool:

- **Мониторы и система**: Ни экран не отключается, ни ПК не переходит в режим ожидания/энергосбережения. Идеально подходит для презентаций или длительных процессов, при которых экран должен оставаться видимым.
- **Мониторы**: Остаётся включённым только экран (без отключения, без заставки). Сам ПК может всё же перейти в режим ожидания по истечении собственного тайм-аута.
- **Система**: ПК не переходит в режим ожидания/энергосбережения, но экран всё же может отключиться согласно настройкам Windows. Полезно, например, для длительных загрузок или вычислений в фоновом режиме.
- **Отключено**: CCTrayTool не вмешивается; действует обычное поведение энергосбережения Windows.

Пункт меню "Сохранить состояние" в подменю "Настройки" раздела KeepAwake заставляет CCTrayTool запоминать последнюю выбранную настройку KeepAwake и автоматически восстанавливать её при следующем запуске.

При закрытии CCTrayTool обычное поведение энергосбережения Windows восстанавливается автоматически.

## 3. AlwaysOnTop - удержание окна поверх других

Сочетание клавиш SHIFT + ALT + T (по умолчанию) постоянно удерживает текущее активное окно поверх других - даже при щелчке по другим окнам. Повторное нажатие снимает эту фиксацию.

При переключении рядом с курсором мыши ненадолго появляется небольшое уведомление, подтверждающее, "остаётся ли окно поверх других" или оно "вернулось в обычный режим". Это уведомление можно включить или отключить через пункт меню "Показывать подсказку".

В меню "AlwaysOnTop" доступны следующие параметры:

- **Горячая клавиша активна**: Полностью включает или отключает сочетание клавиш
- **Настройки**: Подменю (значок шестерёнки) со следующими пунктами:
  - **Изменить горячую клавишу**: Открывает диалоговое окно, в котором можно задать собственное сочетание клавиш (комбинация Ctrl, Alt, Shift, Win и буквы, цифры или функциональной клавиши F1-F12)
  - **Показывать подсказку**: Включает или отключает короткое уведомление на экране при переключении

Примечание: Сам рабочий стол Windows ("Program Manager") нельзя установить в режим "поверх всех окон". Не каждое сочетание клавиш свободно - некоторые уже заняты системой или другими программами. В этом случае появляется уведомление, и необходимо выбрать другое сочетание.

## 4. CloseGuard - блокировка кнопки закрытия

CloseGuard защищает окна от случайного закрытия. Для выбранных окон он блокирует кнопку закрытия (значок "X" в правом верхнем углу окна): кнопка становится серой, а щелчок по ней ничего не делает. Это удобно для программ, которые должны работать постоянно, и для окон, которые то и дело закрывают по ошибке.

Окно можно заблокировать двумя способами:

- **Вручную, с помощью сочетания клавиш**: Щёлкните окно и нажмите CTRL + ALT + X (по умолчанию). Кнопка закрытия этого окна заблокирована. Повторное нажатие сочетания разблокирует её. Окно, разблокированное таким образом, остаётся свободным, даже если подходит под правило, пока его не закроют. Короткое уведомление подтверждает каждое изменение. Блокировка действует, пока окно не будет закрыто или разблокировано.
- **Автоматически, с помощью правил**: Щёлкните окно и нажмите CTRL + ALT + SHIFT + X (по умолчанию). CCTrayTool сохраняет в файле правил правило из заголовка и класса окна и блокирует окно. С этого момента каждое окно, подходящее под правило, блокируется автоматически, как только появляется, - в том числе после перезапуска программы или CCTrayTool.

В меню области уведомлений раздел "CloseGuard" содержит следующие пункты:

- **Заблокировать/разблокировать кнопку закрытия активного окна**: Делает то же, что и первое сочетание клавиш. Пока меню области уведомлений открыто, фокус находится у самого меню; поэтому CloseGuard использует окно, которое было активным непосредственно перед этим.
- **Создать правило для активного окна**: Делает то же, что и второе сочетание клавиш.
- **Показать заблокированные окна**: Показывает, какие окна заблокированы в данный момент (по правилу или вручную, с классом окна в квадратных скобках), и сколько существует правил.

Под ними находится подменю "Настройки" (значок шестерёнки), которое содержит:

- **Автоматически проверять новые окна**: Включено: CloseGuard постоянно наблюдает и блокирует каждое новое окно, подходящее под правило. Выключено: новые окна автоматически не блокируются.
- **Проверять окна, открытые при запуске**: Включено: окна, уже открытые при запуске CCTrayTool, сразу сравниваются с правилами. Выключено: эти окна не затрагиваются; проверяются только окна, открытые позже.
- **Сворачивать окно при щелчке по заблокированному X**: Включено: щелчок по затемнённой кнопке закрытия сворачивает окно вместо того, чтобы ничего не делать. Как и с настоящей кнопкой, окно сворачивается, только если кнопка мыши отпущена тоже над X; если нажать кнопку и отвести курсор, щелчок отменяется. Выключено (по умолчанию): щелчок ничего не делает.
- **Изменить горячую клавишу: блокировка/разблокировка** / **Изменить горячую клавишу: создание правила**: Открывает то же диалоговое окно, что и для AlwaysOnTop, чтобы задать другое сочетание клавиш. Сочетание, которое уже использует другая функция CCTrayTool, отклоняется.
- **Редактировать правила...**: Открывает файл правил в Блокноте (см. ниже). После сохранения и закрытия Блокнота изменённые правила применяются сразу: окна, заблокированные правилом, которое больше не подходит, разблокируются, а новые правила сразу действуют для открытых окон.

CloseGuard в целом включается и отключается пунктом "Включить CloseGuard" в меню "Настройки" раздела "CCTrayTool" (см. раздел 7).

Правила (отдельный файл `CloseGuardRules.ini`, раздел `[Rules]`):

Правила хранятся не в файле настроек, а в отдельном файле: `%LocalAppData%\CCTrayTool\CloseGuardRules.ini`. Он создаётся автоматически. Это файл Unicode, поэтому работают заголовки окон с любыми специальными символами. Блокнот сохраняет этот формат; если файл редактируется другой программой, сохраните его тоже как Unicode (UTF-16), иначе специальные символы могут быть потеряны. Правила перечитываются после закрытия Блокнота, открытого через "Редактировать правила...", и при каждом запуске CCTrayTool.

Каждая строка - это одно правило вида `номер=заголовок|класс`. Заголовок - текст, который должен встречаться где-либо в заголовке окна. Класс - техническое имя типа окна; он должен совпадать точно. Регистр букв не учитывается. Одна из двух частей может быть пустой (знак "|" должен остаться); если заполнены обе, должны совпадать обе. Примеры:

- `1=Calculator|`: любое окно со словом "Calculator" в заголовке
- `2=|Notepad`: любое окно класса "Notepad"
- `3=Untitled|Notepad`: окна класса "Notepad" со словом "Untitled" в заголовке

Сочетание клавиш "создать правило" использует полный текущий заголовок окна. Если заголовок меняется (например, из-за имени открытого документа), позже сократите его через "Редактировать правила..." до неизменной части либо оставьте заголовок пустым и сохраните только класс. Класс заблокированного окна показывает пункт "Показать заблокированные окна". Правило с пустым заголовком и пустым классом игнорируется; используется не более 200 правил.

Параметры в файле настроек (раздел `[CloseGuard]`):

```ini
[CloseGuard]
Enabled=1
HotkeyToggle=^!x
HotkeyAddRule=^!+x
ApplyOnStartup=1
AutoApply=1
PollInterval=500
MinimizeOnClick=0
ClickPollInterval=30
ClickGeometryFallback=1
ClickGeometryExtendLeft=0
ClickGeometryExtendDown=87
ClickDebugOverlay=0
ClickShieldClasses=Chrome_WidgetWin_1,MozillaWindowClass
```

- `Enabled`: 1 = CloseGuard включён, 0 = выключен (как пункт меню "Включить CloseGuard").
- `HotkeyToggle`: Сочетание клавиш для блокировки/разблокировки. `^` = Ctrl, `!` = Alt, `+` = Shift, `#` = Win, затем клавиша. Проще изменить его через пункт меню "Изменить горячую клавишу".
- `HotkeyAddRule`: Сочетание клавиш для "создать правило".
- `ApplyOnStartup`: 1 = окна, открытые при запуске программы, сравниваются с правилами, 0 = не затрагиваются.
- `AutoApply`: 1 = новые окна проверяются автоматически, 0 = нет.
- `PollInterval`: Как часто проверяются окна, в миллисекундах: от 250 до 5000 (по умолчанию: 500). Другие значения исправляются автоматически.
- `MinimizeOnClick`: 1 = щелчок по заблокированной кнопке закрытия сворачивает окно, 0 = ничего не происходит (по умолчанию). Соответствует пункту меню.
- `ClickPollInterval`: Как часто для этого проверяется кнопка мыши, в миллисекундах: от 10 до 100 (по умолчанию: 30). Меньшее значение надёжнее распознаёт очень короткие щелчки, большее требует меньше вычислительного времени. Другие значения исправляются автоматически. Для этого параметра пункта меню нет.
- `ClickGeometryFallback`: 1 = если окно с собственной строкой заголовка (например, Outlook) не сообщает Windows о своей кнопке X, она распознаётся по положению (по умолчанию). 0 = распознаётся только та кнопка X, о которой окно сообщает само.
- `ClickGeometryExtendLeft`: Насколько далеко влево простирается область, в которой X распознаётся по положению, в процентах от ширины X: от 0 до 100 (по умолчанию: 0). Некоторые программы рисуют X левее, чем сообщает Windows. Слишком большое значение заходит на соседнюю кнопку развёртывания.
- `ClickGeometryExtendDown`: Насколько далеко вниз простирается эта область, в процентах от высоты X: от 0 до 100 (по умолчанию: 87). Некоторые программы рисуют X ниже, чем сообщает Windows. Та же цель и те же пределы, что у `ClickGeometryExtendLeft`.
- `ClickDebugOverlay`: 1 = показывает на экране в виде цветных прозрачных прямоугольников области, по которым распознаётся X: красный = область, в которой щелчок считается щелчком по X, синий = область кнопки закрытия, о которой сообщает Windows (или, если Windows её не сообщает, область X, найденная опросом окна), зелёный = щит над X (см. `ClickShieldClasses`). Только для поиска ошибок. 0 = выключено (по умолчанию).
- `ClickShieldClasses`: Классы окон (через запятую) программ, которые сами закрываются при отпускании кнопки мыши, например Edge и Chrome (`Chrome_WidgetWin_1`) и Firefox (`MozillaWindowClass`); по умолчанию оба. Кнопка X такого окна закрывается почти невидимым окном, которое перехватывает щелчок, поэтому окно больше нельзя закрыть кнопкой X. Пусто = нет.

Два сочетания клавиш CloseGuard и сочетание AlwaysOnTop должны отличаться друг от друга. Иначе вместо них используются сочетания по умолчанию.

Полезно знать:

- Блокировка защищает от случайного щелчка по X. В зависимости от программы окно по-прежнему можно закрыть другими способами: с помощью ALT + F4, командой "Закрыть окно" на панели задач, командой выхода в меню самой программы или через диспетчер задач.
- Заблокировать можно только окна с обычной строкой заголовка и системным меню. Программы, которые рисуют собственную строку заголовка (многие современные приложения, некоторые браузеры, приложения из Microsoft Store), могут сохранить рабочий значок X, даже если CloseGuard сообщает, что окно заблокировано. Если у окна вообще нет системного меню, появляется уведомление.
- Сворачивание щелчком: CCTrayTool кратко и регулярно проверяет кнопку мыши (по умолчанию каждые 30 мс), и только пока видно хотя бы одно заблокированное окно. Хук мыши не используется, поэтому мышь и систему замедлить невозможно. В маловероятном случае, когда очень короткий щелчок приходится на момент, когда CCTrayTool занят, он просто не замечается: окно остаётся как есть, а его X остаётся заблокированным.
- Сворачивание щелчком реагирует на основную кнопку мыши (правую, если в Windows кнопки поменяны местами) и только на X заблокированных окон. Сенсорный ввод и ввод пером не распознаются. Если программа игнорирует команду сворачивания, CCTrayTool сворачивает окно напрямую.
- Некоторые программы рисуют строку заголовка сами (например, Outlook). Они не сообщают Windows, где находится их кнопка X, поэтому для распознавания щелчка CCTrayTool вычисляет положение X в правом верхнем углу окна (ключ INI `ClickGeometryFallback`). В файле журнала тогда появляется "recognized by its position".
- Edge, Chrome и другие программы на основе Chromium, а также Firefox сами рисуют кнопку X и сами закрывают окно, когда кнопка мыши отпускается, поэтому заблокированное системное меню их не останавливает. Над кнопкой X таких окон (ключ INI `ClickShieldClasses`, по умолчанию `Chrome_WidgetWin_1,MozillaWindowClass`) CCTrayTool размещает почти невидимое окно, щит. Щелчок попадает в щит, и программа его никогда не видит: ничего не происходит, или окно сворачивается, если включено сворачивание по щелчку. Щит следует за окном и исчезает, пока окно свёрнуто, разблокировано, развёрнуто на весь экран или перекрыто другим окном в месте кнопки X. При `ClickDebugOverlay=1` он показывается зелёным. Пока окно такого класса видно, кнопка мыши проверяется каждые 10 мс, даже если сворачивание по щелчку выключено. Firefox сам рисует строку заголовка, и Windows не сообщает положение его кнопки X; тогда CCTrayTool находит X, опрашивая окно (файл журнала: "found by asking the window"). Запасное распознавание по положению (`ClickGeometryFallback`) используется только для окон, которые не сообщают Windows о своей кнопке X, например Outlook и Word; CCTrayTool один раз опрашивает каждое окно и записывает результат в файл журнала ("probe of the X").
- Окна программ, запущенных от имени администратора, нельзя заблокировать, пока сам CCTrayTool не запущен от имени администратора (правило безопасности Windows). Появляется уведомление.
- Рабочий стол, панель задач и окна самого CCTrayTool никогда не блокируются.
- При разблокировке системное меню окна возвращается к стандартному виду Windows. Пункты, которые программа сама добавила в это меню, могут отсутствовать до перезапуска программы.
- Блокировка действует только пока работает CCTrayTool: при закрытии программы или отключении CloseGuard все окна получают кнопку закрытия обратно. Если CCTrayTool завершён принудительно (например, через диспетчер задач), заблокированные окна остаются заблокированными. Тогда нажмите в таком окне сочетание для блокировки/разблокировки (CCTrayTool должен снова работать) либо закройте окно и откройте его заново.

## 5. Меню быстрого запуска собственных программ

Над разделом KeepAwake меню в области уведомлений показывает раздел "ToolTime": список программ, которые можно запустить одним щелчком. Записи берутся из папки на вашем компьютере (см. раздел 6): каждый ярлык (файл `.lnk`) в этой папке становится пунктом меню, а каждая вложенная папка - подменю.

По умолчанию уже настроено несколько встроенных инструментов Windows, в том числе:

- Калькулятор, Notepad (папка "Office")
- Explorer (прямо в главном меню)
- Командная строка, Редактор реестра, Сетевые настройки, Панель управления, Монитор ресурсов, Монитор производительности, Управление службами, Очистка диска (папка "Система")

Ярлыки, программа которых не найдена на данном компьютере, автоматически не появляются в меню - поэтому сообщение об ошибке не возникает, если какого-либо инструмента нет в системе.

Некоторые записи (например, Командная строка, Редактор реестра) настроены на автоматический запуск с правами администратора (в этом случае Windows запрашивает подтверждение через Контроль учётных записей).

## 6. Добавление собственных инструментов и папок

Инструменты в меню быстрого запуска - это просто ярлыки в папке. Чтобы добавить инструмент, выберите в меню "Настройки" пункт "Открыть папку ToolTime" и поместите ярлык (файл `.lnk`) в открывшуюся папку. CCTrayTool сам замечает изменение и вскоре обновляет меню в области уведомлений. (Если этого не произошло, используйте пункт "Перезагрузить инструменты" в меню "Настройки".)

Быстрый способ создать ярлык: перетащите программу в папку правой кнопкой мыши и выберите "Создать ярлыки".

Папка по умолчанию: `%LocalAppData%\CCTrayTool\ToolTime` (Другую папку можно указать в файле настроек, см. ниже.)

При создании папки ToolTime CCTrayTool помещает в неё также краткий информационный файл ("`ToolTime_Info.txt`", на языке системы). В нём кратко объясняются ограничения и то, как сортировать записи с помощью числа перед именем. Меню игнорирует этот файл; его можно удалить в любой момент.

Как папка превращается в меню:

- **Ярлык (`.lnk`)**: становится пунктом меню. Название - это имя файла; значок - значок ярлыка (если его нет - значок программы, на которую он указывает).
- **Вложенная папка**: становится подменю. Её значок можно изменить, как обычно, в проводнике Windows (Свойства > Настройка > Сменить значок).
- **Порядок**: Сначала идут папки, затем ярлыки, и те и другие по алфавиту. Чтобы задать свой порядок, начните имя с двух или трёх цифр и знака подчёркивания, например "`01_Notepad.lnk`". Число служит только для сортировки и не отображается.
- **Администратор**: Включите "Запуск от имени администратора" в свойствах ярлыка (Ярлык > Дополнительно). При запуске записи Windows запросит подтверждение.
- **Не отображаются**: Скрытые файлы, файлы, не являющиеся ярлыками, ярлыки, программы которых не существует, и пустые папки.

Ограничения - чтобы меню оставалось удобным:

Меню в области уведомлений нельзя прокручивать колесом мыши, только двумя маленькими кнопками со стрелками, а длинное меню вытеснило бы KeepAwake, AlwaysOnTop и настройки за пределы видимой области. Поэтому действуют следующие правила:

- В одном меню отображается не более 15 записей (папки и ярлыки вместе). Это ограничение можно изменить в файле настроек на значение от 10 до 20 (см. ниже).
- Не более 3 уровней меню: меню ToolTime и два уровня подменю. Более глубокие папки игнорируются.
- Не более 400 записей в сумме.

Совет: лучше группируйте множество инструментов по подпапкам, чем держать их в одном длинном списке.

Если ограничение превышено, ничего не теряется незаметно:

- Лишние записи не отображаются. Вместо них в меню появляется неактивная строка вида "... ещё 3 не показано (лимит 15)".
- Появляется уведомление, а в разделе ToolTime отображается запись "(!) ToolTime: обнаружены проблемы - щёлкните для подробностей". Щелчок по ней показывает, что именно было пропущено и почему. Те же сведения записываются в файл журнала (если включено "Создавать файл журнала").
- О слишком глубоко вложенных папках и ярлыках, которые не удаётся прочитать, сообщается таким же образом.

Параметры в файле настроек (раздел `[ToolTime]`):

```ini
[ToolTime]
Enabled=1
MaxEntries=15
Folder=
```

- `Enabled`: 1 = показывать ToolTime, 0 = скрыть (то же, что пункт меню "Включить ToolTime")
- `MaxEntries`: Максимальное число записей в одном меню, от 10 до 20 (по умолчанию: 15). Другие значения исправляются автоматически.
- `Folder`: Необязательно: путь к другой папке ToolTime. Допускаются переменные среды, например `%USERPROFILE%`. Пусто = папка по умолчанию. Если папка не существует, она создаётся.

Чтобы отредактировать файл, выберите в меню "Настройки" пункт "Редактировать файл настроек". После сохранения и закрытия Блокнота CCTrayTool заново читает файл, сразу применяет все изменения (без перезапуска) и перестраивает меню.

Восстановление инструментов по умолчанию: закройте CCTrayTool, удалите папку ToolTime и снова запустите программу - инструменты по умолчанию и информационный файл будут созданы заново.

## 7. Дополнительные настройки

В подменю "Настройки" также доступны:

- **Включить ToolTime**: Полностью включает или отключает весь раздел быстрого запуска инструментов (см. раздел 5). При отключении ни одна из его записей не отображается в меню области уведомлений, независимо от того, что находится в папке ToolTime.
- **Открыть папку ToolTime**: Открывает папку ToolTime в проводнике Windows, чтобы добавлять, переименовывать или удалять ярлыки (см. раздел 6).
- **Перезагрузить инструменты**: Заново читает папку ToolTime и перестраивает меню. Обычно не требуется, так как изменения в папке обнаруживаются автоматически.
- **Включить KeepAwake**: Полностью включает или отключает весь раздел KeepAwake (см. раздел 2). При отключении его записи исчезают из меню области уведомлений, и действует обычное поведение энергосбережения Windows.
- **Включить AlwaysOnTop**: Полностью включает или отключает весь раздел AlwaysOnTop (см. раздел 3). При отключении его записи исчезают из меню области уведомлений, а сочетание клавиш отключается.
- **Включить CloseGuard**: Полностью включает или отключает весь раздел CloseGuard (см. раздел 4). При отключении его записи исчезают из меню области уведомлений, сочетания клавиш отключаются, а все заблокированные окна получают кнопку закрытия обратно.
- **Запускать автоматически**: CCTrayTool будет теперь автоматически запускаться при входе в Windows.
- **Создавать файл журнала**: Записывает подробный журнал всех действий в файл журнала. Полезно для устранения неполадок, не требуется при обычной работе. В файле настроек это запись "`UseLog`" в разделе `[Main]`: 1 = включено; 0, пустая или отсутствующая запись либо любое другое значение = выключено.
- **Просмотреть файл журнала**: Открывает текущий файл журнала в Блокноте.
- **Использовать крупные значки**: Отображает значки в меню области уведомлений крупнее (32 вместо 16 пикселей).
- **Редактировать файл настроек**: Открывает файл конфигурации напрямую для редактирования (см. раздел 6).

## 8. Расположение файлов

CCTrayTool сохраняет свои файлы в профиле пользователя:

- **Конфигурация:** `%LocalAppData%\CCTrayTool\CCTrayTool.ini`
- **Файл журнала:** `%LocalAppData%\CCTrayTool\CCTrayTool.log`
- **Папка ToolTime:** `%LocalAppData%\CCTrayTool\ToolTime\`
- **Правила CloseGuard:** `%LocalAppData%\CCTrayTool\CloseGuardRules.ini`

(Путь можно вставить в адресную строку проводника Windows, чтобы перейти прямо в папку.)

## 9. Завершение работы программы

CCTrayTool закрывается через пункт меню "Выход". При этом автоматически восстанавливается обычное поведение энергосбережения Windows и сохраняется текущая конфигурация.

Все окна, у которых кнопка закрытия заблокирована CloseGuard, при этом снова получают свою кнопку закрытия.
