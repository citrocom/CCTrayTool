# CCTrayTool – Руководство пользователя

[English](../README.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Español](README.es.md) · [Français](README.fr.md) · [Polski](README.pl.md) · [Magyar](README.hu.md) · **Русский**

CCTrayTool - это небольшая утилита для Windows, которая работает в виде значка в области уведомлений (внизу справа, рядом с часами). Она объединяет три полезные функции в одной программе:

1. **KeepAwake** – не позволяет ПК переходить в режим энергосбережения или отключать экран
2. **AlwaysOnTop** – удерживает любое окно поверх других окон с помощью сочетания клавиш
3. **Быстрый запуск инструментов** – запускает часто используемые программы прямо из меню области уведомлений

Все функции управляются через меню, открываемое щелчком правой кнопкой мыши по значку в области уведомлений. Установка не требуется, программу можно запускать напрямую.

CCTrayTool поддерживает следующие языки: английский, немецкий, итальянский, испанский, французский, польский, венгерский и русский. Язык устанавливается автоматически на основе языка системы компьютера.

Системные требования: необходима 64-разрядная версия Windows 10 или новее. Программа не работает в 32-разрядной версии Windows.

## 1. Запуск и первый значок

После запуска в области уведомлений панели задач Windows появляется значок. Цвет значка сразу показывает текущее состояние KeepAwake:

- Белый = KeepAwake отключен (обычное поведение Windows)
- Красный = KeepAwake активен для мониторов
- Синий = KeepAwake активен для системы
- Зелёный = KeepAwake активен для мониторов и системы

Щелчок правой кнопкой мыши по значку открывает меню со всеми функциями. Если значок не виден, стоит проверить область "скрытых значков" (маленькая стрелка на панели задач).

Примечание: CCTrayTool можно запустить только один раз одновременно. Повторный запуск не имеет никакого эффекта, если программа уже работает.

## 2. KeepAwake - предотвращение энергосбережения

В разделе меню "KeepAwake" можно выбрать, что ПК НЕ должен делать, пока запущен CCTrayTool:

- **Мониторы и система**: Ни экран не отключается, ни ПК не переходит в режим ожидания/энергосбережения. Идеально подходит для презентаций или длительных процессов, при которых экран должен оставаться видимым.
- **Мониторы**: Остаётся включённым только экран (без отключения, без заставки). Сам ПК может всё же перейти в режим ожидания по истечении собственного тайм-аута.
- **Система**: ПК не переходит в режим ожидания/энергосбережения, но экран всё же может отключиться согласно настройкам Windows. Полезно, например, для длительных загрузок или вычислений в фоновом режиме.
- **Отключено**: CCTrayTool не вмешивается; действует обычное поведение энергосбережения Windows.

Пункт меню "Сохранить состояние" заставляет CCTrayTool запоминать последнюю выбранную настройку KeepAwake и автоматически восстанавливать её при следующем запуске.

При закрытии CCTrayTool обычное поведение энергосбережения Windows восстанавливается автоматически.

## 3. AlwaysOnTop - удержание окна поверх других

Сочетание клавиш SHIFT + ALT + T (по умолчанию) постоянно удерживает текущее активное окно поверх других - даже при щелчке по другим окнам. Повторное нажатие снимает эту фиксацию.

При переключении рядом с курсором мыши ненадолго появляется небольшое уведомление, подтверждающее, "остаётся ли окно поверх других" или оно "вернулось в обычный режим". Это уведомление можно включить или отключить через пункт меню "Показывать подсказку".

В меню "AlwaysOnTop" доступны следующие параметры:

- **Горячая клавиша активна**: Полностью включает или отключает сочетание клавиш
- **Изменить горячую клавишу**: Открывает диалоговое окно, в котором можно задать собственное сочетание клавиш (комбинация Ctrl, Alt, Shift, Win и буквы, цифры или функциональной клавиши F1-F12)
- **Показывать подсказку**: Включает или отключает короткое уведомление на экране при переключении

Примечание: Сам рабочий стол Windows ("Program Manager") нельзя установить в режим "поверх всех окон". Не каждое сочетание клавиш свободно - некоторые уже заняты системой или другими программами. В этом случае появляется уведомление, и необходимо выбрать другое сочетание.

## 4. Меню быстрого запуска собственных программ

Над разделом KeepAwake меню в области уведомлений показывает раздел "ToolTime": список программ, которые можно запустить одним щелчком. Записи берутся из папки на вашем компьютере (см. раздел 5): каждый ярлык (файл `.lnk`) в этой папке становится пунктом меню, а каждая вложенная папка - подменю.

По умолчанию уже настроено несколько встроенных инструментов Windows, в том числе:

- Калькулятор, Notepad (папка "Office")
- Explorer (прямо в главном меню)
- Командная строка, Редактор реестра, Сетевые настройки, Панель управления, Монитор ресурсов, Монитор производительности, Управление службами, Очистка диска (папка "Система")

Ярлыки, программа которых не найдена на данном компьютере, автоматически не появляются в меню - поэтому сообщение об ошибке не возникает, если какого-либо инструмента нет в системе.

Некоторые записи (например, Командная строка, Редактор реестра) настроены на автоматический запуск с правами администратора (в этом случае Windows запрашивает подтверждение через Контроль учётных записей).

## 5. Добавление собственных инструментов и папок

Инструменты в меню быстрого запуска - это просто ярлыки в папке. Чтобы добавить инструмент, выберите в меню "Настройки" пункт "Открыть папку ToolTime" и поместите ярлык (файл `.lnk`) в открывшуюся папку. CCTrayTool сам замечает изменение и вскоре обновляет меню в области уведомлений. (Если этого не произошло, используйте пункт "Перезагрузить инструменты" в меню "Настройки".)

Быстрый способ создать ярлык: перетащите программу в папку правой кнопкой мыши и выберите "Создать ярлыки".

Папка по умолчанию: `%LocalAppData%\CCTrayTool\ToolTime` (Другую папку можно указать в файле настроек, см. ниже.)

При создании папки ToolTime CCTrayTool помещает в неё также краткий информационный файл ("`ToolTime_Info.txt`", на языке системы). В нём кратко объясняются ограничения и то, как сортировать записи с помощью числа перед именем. Меню игнорирует этот файл; его можно удалить в любой момент.

Как папка превращается в меню:

- **Ярлык (`.lnk`)**: становится пунктом меню. Название - это имя файла; значок - значок ярлыка (если его нет - значок программы, на которую он указывает).
- **Вложенная папка**: становится подменю. Её значок можно изменить, как обычно, в проводнике Windows (Свойства > Настройка > Сменить значок).
- **Порядок**: Сначала идут папки, затем ярлыки, и те и другие по алфавиту. Чтобы задать свой порядок, начните имя с двух или трёх цифр и знака подчёркивания, например "`01_Notepad.lnk`". Число служит только для сортировки и не отображается.
- **Администратор**: Включите "Запуск от имени администратора" в свойствах ярлыка (Ярлык > Дополнительно). При запуске записи Windows запросит подтверждение.
- **Не отображаются**: Скрытые файлы, файлы, не являющиеся ярлыками, ярлыки, программы которых не существует, и пустые папки.

Ограничения - чтобы меню оставалось удобным:

Меню в области уведомлений нельзя прокручивать колесом мыши, только двумя маленькими кнопками со стрелками, а длинное меню вытеснило бы KeepAwake, AlwaysOnTop и настройки за пределы видимой области. Поэтому действуют следующие правила:

- В одном меню отображается не более 15 записей (папки и ярлыки вместе). Это ограничение можно изменить в файле настроек на значение от 10 до 20 (см. ниже).
- Не более 3 уровней меню: меню ToolTime и два уровня подменю. Более глубокие папки игнорируются.
- Не более 400 записей в сумме.

Совет: лучше группируйте множество инструментов по подпапкам, чем держать их в одном длинном списке.

Если ограничение превышено, ничего не теряется незаметно:

- Лишние записи не отображаются. Вместо них в меню появляется неактивная строка вида "... ещё 3 не показано (лимит 15)".
- Появляется уведомление, а в разделе ToolTime отображается запись "(!) ToolTime: обнаружены проблемы - щёлкните для подробностей". Щелчок по ней показывает, что именно было пропущено и почему. Те же сведения записываются в файл журнала (если включено "Создавать файл журнала").
- О слишком глубоко вложенных папках и ярлыках, которые не удаётся прочитать, сообщается таким же образом.

Параметры в файле настроек (раздел `[ToolTime]`):

```ini
[ToolTime]
Enabled=1
MaxEntries=15
Folder=
```

- `Enabled`: 1 = показывать ToolTime, 0 = скрыть (то же, что пункт меню "Включить ToolTime")
- `MaxEntries`: Максимальное число записей в одном меню, от 10 до 20 (по умолчанию: 15). Другие значения исправляются автоматически.
- `Folder`: Необязательно: путь к другой папке ToolTime. Допускаются переменные среды, например `%USERPROFILE%`. Пусто = папка по умолчанию. Если папка не существует, она создаётся.

Чтобы отредактировать файл, выберите в меню "Настройки" пункт "Редактировать файл настроек". После сохранения и закрытия Блокнота CCTrayTool заново читает файл, сразу применяет все изменения (без перезапуска) и перестраивает меню.

Восстановление инструментов по умолчанию: закройте CCTrayTool, удалите папку ToolTime и снова запустите программу - инструменты по умолчанию и информационный файл будут созданы заново.

## 6. Дополнительные настройки

В подменю "Настройки" также доступны:

- **Включить ToolTime**: Полностью включает или отключает весь раздел быстрого запуска инструментов (см. раздел 4). При отключении ни одна из его записей не отображается в меню области уведомлений, независимо от того, что находится в папке ToolTime.
- **Открыть папку ToolTime**: Открывает папку ToolTime в проводнике Windows, чтобы добавлять, переименовывать или удалять ярлыки (см. раздел 5).
- **Перезагрузить инструменты**: Заново читает папку ToolTime и перестраивает меню. Обычно не требуется, так как изменения в папке обнаруживаются автоматически.
- **Включить KeepAwake**: Полностью включает или отключает весь раздел KeepAwake (см. раздел 2). При отключении его записи исчезают из меню области уведомлений, и действует обычное поведение энергосбережения Windows.
- **Включить AlwaysOnTop**: Полностью включает или отключает весь раздел AlwaysOnTop (см. раздел 3). При отключении его записи исчезают из меню области уведомлений, а сочетание клавиш отключается.
- **Запускать автоматически**: CCTrayTool будет теперь автоматически запускаться при входе в Windows.
- **Создавать файл журнала**: Записывает подробный журнал всех действий в файл журнала. Полезно для устранения неполадок, не требуется при обычной работе. В файле настроек это запись "`UseLog`" в разделе `[Main]`: 1 = включено; 0, пустая или отсутствующая запись либо любое другое значение = выключено.
- **Просмотреть файл журнала**: Открывает текущий файл журнала в Блокноте.
- **Использовать крупные значки**: Отображает значки в меню области уведомлений крупнее (32 вместо 16 пикселей).
- **Редактировать файл настроек**: Открывает файл конфигурации напрямую для редактирования (см. раздел 5).

## 7. Расположение файлов

CCTrayTool сохраняет свои файлы в профиле пользователя:

- **Конфигурация:** `%LocalAppData%\CCTrayTool\CCTrayTool.ini`
- **Файл журнала:** `%LocalAppData%\CCTrayTool\CCTrayTool.log`
- **Папка ToolTime:** `%LocalAppData%\CCTrayTool\ToolTime\`

(Путь можно вставить в адресную строку проводника Windows, чтобы перейти прямо в папку.)

## 8. Завершение работы программы

CCTrayTool закрывается через пункт меню "Выход". При этом автоматически восстанавливается обычное поведение энергосбережения Windows и сохраняется текущая конфигурация.
